StreamCasterWeb-Video auf den Fernseher
Ultrakurzanleitung

In 3 Schritten auf dem TV.

Kein Kabel, keine App auf dem Handy. Der Fernseher zeigt einen Code — das Handy schickt den Stream.

1
Am Fernseher
Browser öffnen, Adresse eingeben
Fire TV (Silk), Android-TV oder Smart-TV-Browser. Es erscheint ein 6-stelliger Code und ein QR-Code.
streamcaster.pages.dev/r
2
Am Handy oder PC
Code scannen — oder eintippen
QR mit der Handy-Kamera scannen: die Seite öffnet sich und verbindet automatisch. Alternativ Code eingeben und Connect drücken.
streamcaster.pages.dev
3
Streamen
Link einfügen, Datei senden oder Bildschirm spiegeln
Der TV springt auf „Connected" und spielt ab. Lautstärke und Pause steuerst du am Handy oder mit der TV-Fernbedienung.
Nur für iPhone / iPad (AirPlay): einmalig die Receiver-App auf dem Fire TV installieren
  1. Downloader auf dem Fire TV installieren (Amazon Appstore, kostenlos).
  2. In Downloader eingeben: streamcaster.pages.dev/apk — „Apps aus unbekannten Quellen" erlauben.
  3. StreamCaster Receiver starten → Code erscheint → am iPhone über AirPlay spiegeln.

Wenn etwas hakt

TV wartet, aber nichts passiert
Code erneut scannen — der QR verbindet direkt, ohne Tippen.
Video startet nicht
Manche Portale blocken fremde Player. Dann im Sender „Browse & cast" nutzen und dort abspielen.
iPhone spiegelt nicht
AirPlay braucht die Receiver-App auf dem Fire TV (siehe oben).
